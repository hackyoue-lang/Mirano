# Vider son cache

## Comment effacer son cache FiveM

Pour vider le **cache** de **FiveM**, suivez les **étapes ci-dessous** :

1. **Fermez** complètement **l'application** **FiveM**.
2. Faites un **clic droit** sur l'icône FiveM présente sur votre bureau Windows, puis sélectionnez "**Ouvrir l'emplacement du fichier**".
3. Ensuite, accédez au **dossier** "**FiveM Application Data**". Alternativement, utilisez l'explorateur Windows pour naviguer vers : "**C:\Users\[votre nom d'utilisateur]\AppData\Local\FiveM**".
4. Puis, **supprimez** les dossiers suivants :
   - **crashes** : ce dossier contient les rapports de plantages. Leur suppression ne causera aucun problème de fonctionnement.
   - **logs** : ce dossier stocke les fichiers journaux. Leur suppression peut aider à résoudre certains problèmes sans affecter le fonctionnement de FiveM.
5. Ensuite, accédez au dossier nommé "**data**" et procédez comme suit :
6. **Supprimez** les sous-dossiers suivants :
   - **cache** : ce dossier contient des fichiers temporaires et des données en cache qui peuvent être supprimés en toute sécurité pour libérer de l'espace et résoudre des problèmes de performance.
   - **nui-storage** : ce dossier stocke des données temporaires liées à l'interface utilisateur. Sa suppression peut aider à résoudre des problèmes d'affichage ou de fonctionnement.
   - **server-cache** : ce dossier contient des fichiers de cache relatifs aux serveurs auxquels vous vous connectez. Supprimer ce dossier peut aider à résoudre des problèmes de connexion ou de performance.
   - **server-cache-priv** : ce dossier stocke des données de cache privées relatives aux serveurs. Sa suppression peut également aider à résoudre des problèmes de connexion ou de performance.

> [!DANGER]
> **Ne supprimez pas le dossier appelé** **game-storage** : ce dossier contient des données cruciales pour le bon fonctionnement de FiveM. Supprimer ce dossier pourrait entraîner des problèmes importants avec le jeu.
