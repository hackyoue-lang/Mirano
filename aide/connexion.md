# Connexion

## Première méthode

1. Pour rejoindre notre serveur **Mirano**, cliquez sur "**Jouer**".
2. Ensuite, recherchez "**Mirano**" dans la liste des serveurs FiveM.
3. Puis, cliquez sur "**Mirano**".
4. Enfin, cliquez sur "**Se connecter**".

---

## Deuxième méthode

1. Dans le menu FiveM, appuyez sur la touche **F8** pour ouvrir la **console**.
2. **Collez** la commande **`connect 83.150.218.28:30100`** dans la console.
3. Appuyez sur **Entrée** pour vous connecter au serveur !
