# Comment acheter des MiranoCoins

## Premièrement, voici le lien de la boutique Mirano

👉 [https://boutique.mirano.fr/](https://boutique.mirano.fr/)

1. Pour **débuter**, accédez d'abord au **bouton** **MiranoCoins**.
2. Sélectionnez la **quantité** désirée de **MiranoCoins**, puis cliquez sur "**Acheter**".
3. Ensuite, cliquez sur "**Ajouter au panier**".
4. **Connectez-vous** à votre compte **FiveM** en utilisant le bouton "**Se connecter avec FiveM**".
5. Une fois sur le site **FiveM**, cliquez sur "**Continuer**" si votre compte FiveM est déjà connecté. Sinon, **connectez-vous**.
6. Après avoir cliqué sur "**Continuer**", vous serez redirigé vers le **site de la boutique**. Si vous le souhaitez, vous pouvez **ajouter votre pseudo Discord** pour obtenir le rôle "**Contributeur**" sur le **serveur** (optionnel).
7. Ensuite, vous devrez saisir votre **UUID**. Pour le trouver, **rendez-vous en jeu**, appuyez sur **F1**, puis accédez à l'onglet "**UUID**", puis cliquez sur "**Continuer**".
8. Une fois votre **UUID** saisi, vous serez **redirigé** vers une **nouvelle page**. Appuyez sur "**Proceed to Checkout**".
9. Vous serez ensuite **redirigé** vers **une page de paiement**. Si vous souhaitez ajouter un **bonus**, vous pouvez le **faire**. Sinon, appuyez sur "**Continuer vers le paiement**".
10. **Choisissez** ensuite votre **mode de paiement**.

Enfin, une fois le **paiement effectué**, vous verrez votre **numéro de commande** **Tebex** (nommé "tbx"). Nous vous conseillons de le **prendre en capture d'écran** au cas où un **problème surviendrait** avec votre **commande**.

> [!WARNING]
> Si vous **rencontrez** un **problème**, suivez les **instructions** sur la page [Remboursement](remboursement.md).
