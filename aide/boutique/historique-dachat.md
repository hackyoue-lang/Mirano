# Historique d'achat

## Comment voir son historique d'achat Tebex

Si votre **paiement** a rencontré un **problème**, nous vous recommandons de consulter votre **historique** sur Tebex afin que nous puissions vous rembourser pour votre achat. Veuillez suivre les étapes suivantes :

1. Rendez-vous sur le **lien ci-dessous** :
   [https://checkout.tebex.io/payment-history/login](https://checkout.tebex.io/payment-history/login)
2. Entrez votre **adresse e-mail** (celle que vous avez utilisée pour effectuer l'achat sur la boutique).
3. Vous **recevrez** ensuite un **e-mail** à cette même adresse vous permettant **d'accéder à votre historique de paiement**.

> [!WARNING]
> Si vous **rencontrez** un **problème**, suivez les **instructions** sur la page [Remboursement](remboursement.md).
