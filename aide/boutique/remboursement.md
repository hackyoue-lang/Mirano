# Remboursement

En règle **générale**, pour que votre **demande de remboursement** soit **traitée**, il est essentiel de **fournir des preuves**, à moins que dans certaines **situations spécifiques**, les remboursements **ne soient pas applicables**.

Si vous n'avez **pas reçu ce que vous avez acheté dans la boutique**, que ce soit des **MiranoCoins**, un **abonnement VIP**, ou des **extras** tels que l'achat d'une organisation ou d'une entreprise, nous vous recommandons de **suivre les étapes suivantes pour obtenir un remboursement** :

- 💸 [Si vous n'avez pas reçu les MiranoCoins](remboursement/miranocoin-non-recu.md)
- 🚫 [Si vous n'avez pas reçu l'abonnement VIP](remboursement/vip-non-recu.md)
- 🎁 [Si vous n'avez pas reçu votre extra](remboursement/extra-non-recu.md)
