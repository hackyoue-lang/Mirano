# ❌ Arrêter un VIP

Si vous **souhaitez** **annuler** votre **abonnement VIP**, veuillez suivre les **instructions** ci-dessous :

1. Veuillez vous rendre sur le **lien ci-dessous** : [https://checkout.tebex.io/payment-history/login](https://checkout.tebex.io/payment-history/login)
2. Entrez votre **adresse e-mail** (celle que vous avez utilisée pour effectuer l'achat sur la boutique).
3. Une fois arrivé sur **cette page**, veuillez cliquer sur "**Subscriptions**".
4. Ensuite, cliquez sur "**Manage**" à côté de votre **abonnement** (veuillez faire attention à ne pas confondre avec vos paiements Tebex).
5. Enfin, cliquez sur "**Cancel**" pour **résilier** votre **abonnement** (notez que si vous annulez votre abonnement VIP, il restera valable jusqu'à sa date d'expiration, donc pas d'inquiétude).
